# Security Digest — 2026-08-30

## Database

Microsoft SQL Server CVE-2019-1068 is the single most urgent item this cycle: CISA confirms active exploitation with a hard remediation deadline of August 29, 2026, requiring immediate mitigation under BOD 26-04. In parallel, PostgreSQL faces a batch of ten high-severity (CVSS 8.8) vulnerabilities enabling arbitrary code execution via heap overflows, integer wraparounds, and type confusion across core components including regexp, plperl, pg_stat_statements, and fuzzystrmatch, all requiring upgrade to versions 18.6, 17.11, 16.15, 15.19, or 14.24.

### Formal Vulnerabilities

#### Microsoft SQL Server — CVE-2019-1068 (CVSS UNSCORED — CISA-confirmed active exploitation) 🔴 ACTIVELY EXPLOITED (CISA KEV)
**Summary:** A remote code execution vulnerability in Microsoft SQL Server allows an attacker to execute code in the context of the SQL Server Database Engine service account. CISA has confirmed active exploitation with a remediation due date of August 29, 2026.
**Affected Features / Interoperability:** SQL Server Database Engine service account context; downstream impact includes potential full compromise of the database engine process.
**Source:**
- https://nvd.nist.gov/vuln/detail/CVE-2019-1068
**Actions:**
- Fix: Apply mitigations in accordance with vendor instructions and CISA BOD 26-04; discontinue use of the product if mitigations are unavailable. Specific patched version not listed in provided data.
- Workaround: No workaround specified in source data.
- Tradeoff: No significant tradeoff specified.

## Cloud Security

The most urgent item in today's cloud security digest is CVE-2026-66384 in JFrog Artifactory, a CISA KEV-confirmed vulnerability allowing authenticated users to write data outside Docker cache paths under specific remote-repository conditions, with a mandatory remediation deadline of September 10, 2026. This vulnerability directly impacts Docker container image storage and could lead to unauthorized data manipulation or container compromise if exploited.

### Formal Vulnerabilities

#### Docker — CVE-2026-66384 (UNSCORED — CISA-confirmed active exploitation)
**Summary:** An authenticated user can write data outside the intended Docker cache path in JFrog Artifactory under specific remote-repository configurations. Exploitation requires valid credentials and access to Artifactory's remote repository settings. The vulnerability is actively exploited in the wild per CISA KEV designation.

**Affected Features / Interoperability:** Impacts Docker image caching and storage mechanisms within Artifactory's remote repository configurations. Could disrupt container image integrity, replication workflows, and downstream CI/CD pipelines relying on Artifactory as a Docker registry.

**Source:** [https://nvd.nist.gov/vuln/detail/CVE-2026-66384](https://nvd.nist.gov/vuln/detail/CVE-2026-66384)

**Actions:**
- Fix: Apply mitigations per JFrog's guidance and CISA BOD 26-04 requirements.
- Workaround: Restrict remote repository configurations and enforce strict access controls until patched.
- Tradeoff: No significant tradeoff if mitigations are properly implemented.
