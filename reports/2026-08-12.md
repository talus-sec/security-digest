# Security Digest — 2026-08-12

## Database

The most urgent vulnerability is CVE-2026-49261 in MySQL/MariaDB, a critical flaw (CVSS 10.0) allowing remote code execution via the `wsrep_notify_cmd` feature in Galera cluster configurations, which could lead to full system compromise if exploited. This vulnerability requires immediate patching or disabling of the affected feature to prevent potential attacks.

### Formal Vulnerabilities

#### MySQL — CVE-2026-49261 (CVSS 10.0 CRITICAL)
**Summary:** A critical vulnerability in MariaDB server versions 10.6.1–10.6.26, 10.11.1–10.11.17, 11.4.1–11.4.11, 11.8.1–11.8.7, and 12.3.1 with `wsrep_notify_cmd` enabled allows execution of arbitrary shell commands embedded in joiner node names during cluster replication. Exploitation requires network access to the cluster and control over the joiner node's hostname.

**Affected Features / Interoperability:** Impacts Galera cluster replication functionality. Could disrupt multi-node database deployments and compromise cluster integrity.

**Source:** [GitHub Advisory](https://github.com/MariaDB/server/security/advisories/GHSA-3p3m-4x7c-p4pw), [Red Hat Errata](https://access.redhat.com/errata/RHSA-2026:25143)

**Actions:**
- Fix: Upgrade to MariaDB 10.6.27, 10.11.18, 11.4.12, 11.8.8, or 12.3.2
- Workaround: Disable `wsrep_notify_cmd` configuration option
- Tradeoff: Disables cluster node notification functionality

## Cloud Security

The most urgent issue is **CVE-2026-50516** in Microsoft Azure Kubernetes Service (AKS), a CISA KEV-confirmed vulnerability allowing unauthorized privilege escalation via missing authentication. This actively exploited flaw poses an immediate risk to cloud infrastructure, requiring urgent patching or mitigation to prevent unauthorized access and lateral movement.

#### Microsoft Azure — CVE-2026-50516 (CVSS 9.4 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)
**Summary:** A critical authentication bypass in Azure Kubernetes Service allows attackers to elevate privileges over the network without authentication. This could enable full cluster compromise.
**Affected Features / Interoperability:** Impacts AKS cluster management and any services relying on Kubernetes API access. Could disrupt cluster operations and integrations requiring secure authentication.
**Source:** [Microsoft Security Response Center](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50516)
**Actions:**
- Fix: Upgrade to the latest Azure AKS patch or apply Microsoft's security update.
- Workaround: Restrict network access to AKS clusters and enforce strict IAM policies.
- Tradeoff: Workarounds may reduce cluster accessibility for legitimate users.
