## Executive Summary  
The most urgent vulnerability is **CVE-2026-49261** in MariaDB Server (a MySQL fork), which allows unauthenticated remote attackers to execute arbitrary shell commands via the `wsrep_notify_cmd` feature. ## MySQL  

### Part A — Formal Vulnerabilities  

#### CVE-2026-49261 (CVSS 10.0 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)  
**Summary:** A critical flaw in MariaDB Server versions 10.6.1–10.6.26, 10.11.1–10.11.17, 11.4.1–11.4.11, 11.8.1–11.8.7, and 12.3.1 allows unauthenticated attackers to execute arbitrary shell commands by embedding them in the name of a joiner node when `wsrep_notify_cmd` is enabled.  
**Affected Features / App Interoperability:** Galera Cluster replication (`wsrep_notify_cmd` feature). Disabling this feature breaks cluster node notifications.  
**Source:**  
- https://github.com/MariaDB/server/security/advisories/GHSA-3p3m-4x7c-p4pw  
- https://jira.mariadb.org/browse/MDEV-39721  
**Actions:**  
- **Fix:** Upgrade to MariaDB 10.6.27, 10.11.18, 11.4.12, 11.8.8, or 12.3.2.  
- **Workaround:** Disable `wsrep_notify_cmd` immediately.  
- **Tradeoff:** Disables cluster node notification functionality.  

#### CVE-2026-72869 (CVSS 9.9 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)  
**Summary:** An authenticated attacker with backup:restore permissions in Dokploy versions prior to 0.29.13 can inject shell commands via the `databaseName` parameter during backup restoration, leading to arbitrary command execution in the Docker host context.  
**Affected Features / App Interoperability:** Dokploy’s backup/restore functionality. No direct database component is affected, but exploitation impacts the host system.  
**Source:**  
- https://github.com/Dokploy/dokploy/security/advisories/GHSA-f7mp-9jfp-mjrr  
**Actions:**  
- **Fix:** Upgrade to Dokploy 0.29.13.  
- **Workaround:** Restrict backup:restore permissions to trusted users.  
- **Tradeoff:** Limits self-service backup restoration capabilities.  

#### CVE-2026-18617 (CVSS 8.8 HIGH)  
**Summary:** A flaw in the Data Science Pipelines Operator (DSPO) allows namespace editors to inject dangerous parameters into MySQL DSN strings, enabling `LOCAL INFILE` functionality to exfiltrate sensitive files like service account tokens.  
**Affected Features / App Interoperability:** DSPO’s MySQL data source configuration. Could lead to privilege escalation in Kubernetes clusters.  
**Source:**  
- https://access.redhat.com/errata/RHSA-2026:53261  
**Actions:**  
- **Fix:** Apply Red Hat patches (RHSA-2026:53261–53263).  
- **Workaround:** Restrict namespace editor permissions.  
- **Tradeoff:** Limits namespace editor autonomy.  

#### CVE-2026-48774 (CVSS 7.5 HIGH)  
**Summary:** ProxySQL versions 3.0.0–3.0.8 violate their read-only contract for MySQL targets by allowing multi-statement SQL injection via the GenAI/MCP `run_sql_readonly` tool.  
**Affected Features / App Interoperability:** ProxySQL’s MCP endpoint. Could disrupt database operations if exploited.  
**Source:**  
- https://github.com/sysown/proxysql/security/advisories/GHSA-7wh6-2vcc-gcm4  
**Actions:**  
- **Fix:** Upgrade to ProxySQL 3.0.9.  
- **Workaround:** Disable MCP unless required; restrict network exposure; use read-only database users.  
- **Tradeoff:** Disables MCP functionality; may require reconfiguration of dependent tools.
