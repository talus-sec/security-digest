# Security Digest — 2026-08-12

## Database

The most urgent issue is **CVE-2026-49261** in MariaDB (grouped under MySQL), a critical 10.0 CVSS vulnerability allowing remote code execution via the `wsrep_notify_cmd` feature when Galera cluster replication is enabled, with no authentication required. This is actively exploited in the wild per CISA KEV, demanding immediate patching or disabling the feature. Additional high-severity vulnerabilities in PostgreSQL, MongoDB, and Redis require attention, including unauthenticated SQL injection in PostgreSQL, memory corruption in MongoDB, and denial-of-service risks in Redis via Netty-based clients.

### Formal Vulnerabilities

#### MySQL — CVE-2026-49261 (CVSS 10.0 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)
**Summary:** MariaDB server versions 10.6.1–10.6.26, 10.11.1–10.11.17, 11.4.1–11.4.11, 11.8.1–11.8.7, and 12.3.1 with `wsrep_notify_cmd` enabled execute arbitrary shell commands embedded in joiner node names during cluster replication. Attackers can exploit this remotely without authentication by crafting malicious node names.

**Affected Features / Interoperability:** Galera cluster replication (`wsrep_notify_cmd` module). Breaks cluster security and enables full system compromise.

**Source:** [GitHub Advisory](https://github.com/MariaDB/server/security/advisories/GHSA-3p3m-4x7c-p4pw), [Red Hat Errata](https://access.redhat.com/errata/RHSA-2026:25143)

**Actions:**
- Fix: Upgrade to MariaDB 10.6.27, 10.11.18, 11.4.12, 11.8.8, or 12.3.2.
- Workaround: Disable `wsrep_notify_cmd` immediately.
- Tradeoff: Disables cluster node notification functionality.

## Cloud Security

This week's cloud security landscape is dominated by a cluster of critical Kubernetes privilege-escalation flaws, several of which are actively being exploited in the wild. The single most urgent item is CVE-2026-14450, a confirmed CISA KEV entry affecting the MaaS API in Red Hat OpenShift AI, which allows any pod in the cluster to forge authentication headers and mint ServiceAccount tokens in other tenants' namespaces. This is compounded by CVE-2026-10090, a critical flaw in Red Hat ACM's Application Subscription controller that lets namespace-scoped "edit" users escalate to cluster-admin via crafted Helm charts. Both vulnerabilities enable full cluster compromise and require immediate patching.

**Summary:** A missing authentication check in Azure Kubernetes Service allows an unauthenticated, network-reachable attacker to elevate privileges. This is a CISA KEV-confirmed vulnerability with active exploitation reported.

**Affected Features / Interoperability:** Impacts Azure Kubernetes Service (AKS) authentication and authorization mechanisms. Could affect cluster management APIs, node pool operations, and any AAD-integrated workloads relying on AKS-managed identities.

**Source:** https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50516
