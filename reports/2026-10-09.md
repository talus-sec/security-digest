# Security Digest — 2026-10-09

User Safety: safe

## Cloud Security

The most urgent issue is **CVE-2026-85594** in Traefik (Kubernetes), a CISA KEV-confirmed critical vulnerability allowing namespace bypass and credential theft via misconfigured middleware injection. Immediate patching to v3.7.12 is required. Additional critical vulnerabilities in Traefik, Crawl4AI, and Contrast require urgent attention, with two more KEV entries (CVE-2026-85596 and CVE-2026-88877) demanding immediate remediation. Docker and Kubernetes systems face active exploitation risks, while Contrast’s confidential computing runtime has multiple high-severity flaws affecting integrity and access controls.

### Formal Vulnerabilities

#### Kubernetes — CVE-2026-85594 (CVSS 9.8 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)
**Summary:** Traefik v3.7.1 fails to enforce crossProviderNamespaces restrictions, allowing namespace-limited tenants to inject operator-owned middlewares and recover backend credentials. Exploitable via Kubernetes Ingress provider annotations.
**Affected Features / Interoperability:** Kubernetes Ingress provider, Service annotations, middleware injection. Could compromise backend credentials and tenant isolation.
**Source:** [GitHub Advisory](https://github.com/traefik/traefik/security/advisories/GHSA-m6wx-622r-48r9), [VulnCheck](https://www.vulncheck.com/advisories/traefik-3.7.1-crossprovidernamespaces-bypass-via-service-middleware)
**Actions:**
- Fix: Upgrade to Traefik v3.7.12.
- Workaround: Restrict tenant access to Service annotations; audit middleware usage.
- Tradeoff: No significant tradeoff if patched immediately.

#### Kubernetes — CVE-2026-85596 (CVSS 9.8 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)
**Summary:** Traefik v3.7.0–v3.7.10 has an authentication bypass in Kubernetes Ingress NGINX provider due to TLS option naming conflicts, allowing unauthenticated access to protected routes.
**Affected Features / Interoperability:** TLS configuration, NGINX Ingress provider, client certificate authentication. Could bypass TLS client verification.
**Source:** [GitHub Advisory](https://github.com/traefik/traefik/security/advisories/GHSA-j994-9gqj-9hwq), [VulnCheck](https://www.vulncheck.com/advisories/traefik-3.7-authentication-bypass-via-tls-option-conflict)
**Actions:**
- Fix: Upgrade to Traefik v3.7.11.
- Workaround: Disable conflicting Ingress routes; enforce strict TLS option naming.
- Tradeoff: May require reconfiguration of TLS settings.

#### Kubernetes — CVE-2026-88877 (CVSS 9.8 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)
**Summary:** Traefik v3.7.0–v3.7.11 mishandles Ingresses with both authentication and www-redirect annotations, creating a sibling router that bypasses authentication for non-matching requests.
**Affected Features / Interoperability:** Ingress authentication, redirect middleware, host matching. Could expose protected backends without authentication.
**Source:** [GitHub Advisory](https://github.com/traefik/traefik/security/advisories/GHSA-cjr6-pf59-jq29), [VulnCheck](https://www.vulncheck.com/advisories/traefik-3.7.0-authentication-bypass-via-from-to-www-redirect)
**Actions:**
- Fix: Upgrade to Traefik v3.7.12.
- Workaround: Avoid combining authentication and redirect annotations; validate host patterns.
- Tradeoff: May require restructuring Ingress configurations.

#### Kubernetes — CVE-2026-100833 (CVSS 9.6 CRITICAL)
**Summary:** Contrast v1.14.0–v1.23.1 generates runtime policies that fail to verify container image digests, allowing image substitution via Kata agent API.
**Affected Features / Interoperability:** Container image policies, Kata Containers, confidential computing integrity. Could enable arbitrary code execution in confidential containers.
**Source:** [GitHub Advisory](https://github.com/edgelesssys/contrast/security/advisories/GHSA-m2qg-wrxv-h898), [VulnCheck](https://www.vulncheck.com/advisories/contrast-before-1.23.1-image-substitution-via-policy-generation)
**Actions:**
- Fix: Upgrade to Contrast v1.23.1.
- Workaround: Manually enforce image digest verification in policies.
- Tradeoff: May require policy adjustments.

#### Kubernetes — CVE-2026-103413 (CVSS 8.8 HIGH)
**Summary:** Apache Camel Karavan v4.0.0–v4.22.0 applies arbitrary Kubernetes resources from `kubernetes.yaml` without validation, enabling privilege escalation.
**Affected Features / Interoperability:** Karavan deployment, Kubernetes resource management, pod security options. Could allow hostNetwork, privileged containers, or capability escalation.
**Source:** [Apache Advisory](https://camel.apache.org/security/CVE-2026-103413.html), [GitHub Commit](https://github.com/apache/camel-karavan/commit/a773db372eab9f180110ad6129d58004a1bce571)
**Actions:**
- Fix: Upgrade to Karavan v4.22.1.
- Workaround: Restrict Karavan’s service account permissions; validate `kubernetes.yaml` before deployment.
- Tradeoff: May slow deployment workflows.

#### Kubernetes — CVE-2026-55797 (CVSS 8.8 HIGH)
**Summary:** Argo CD v2.11.0–v3.6.0-rc2 has command injection in SSH Git proxy handling, allowing credential theft via crafted proxy URLs.
**Affected Features / Interoperability:** Argo CD repo-server, SSH Git proxy, credential management. Could expose Git, Helm, and OCI credentials.
**Source:** [GitHub Releases](https://github.com/argoproj/argo-cd/releases/tag/v3.3.15), [GitHub PR](https://github.com/argoproj/argo-cd/pull/15864)
**Actions:**
- Fix: Upgrade to Argo CD v3.3.15, v3.4.10, v3.5.4, or v3.6.0-rc2.
- Workaround: Avoid SSH Git repos with proxy URLs; audit repo configurations.
- Tradeoff: May require reverting to HTTPS-based repos.

#### Kubernetes — CVE-2026-65601 (CVSS 8.8 HIGH)
**Summary:** Traefik v3.7.0–v3.7.6 uses backend Service namespace for HTTPRoute extensionRef resolution, enabling unauthorized middleware injection.
**Affected Features / Interoperability:** Gateway API provider, HTTPRoute, middleware binding. Could inject trusted headers into downstream requests.
**Source:** [GitHub Advisory](https://github.com/traefik/traefik/security/advisories/GHSA-qq9q-x9w4-chhj), [VulnCheck](https://www.vulncheck.com/advisories/traefik-before-namespace-confusion-via-httproute-extensionref)
**Actions:**
- Fix: Upgrade to Traefik v3.7.7.
- Workaround: Restrict HTTPRoute authors’ namespace access; audit extensionRef usage.
- Tradeoff: May require namespace isolation policies.

#### Kubernetes — CVE-2026-65602 (CVSS 8.8 HIGH)
**Summary:** Traefik v3.6.0–v3.7.6 fails to enforce crossProviderNamespaces for IngressRouteTCP serversTransport, allowing mTLS credential injection.
**Affected Features / Interoperability:** IngressRouteTCP, TCP serversTransport, mTLS configuration. Could expose client certificates and SPIFFE identities.
**Source:** [GitHub Advisory](https://github.com/traefik/traefik/security/advisories/GHSA-42cj-m3vj-89wv), [VulnCheck](https://www.vulncheck.com/advisories/traefik-before-ingressroutetcp-serverstransport-namespace-bypass)
**Actions:**
- Fix: Upgrade to Traefik v3.6.23 or v3.7.7.
- Workaround: Disable TCP serversTransport; restrict IngressRouteTCP permissions.
- Tradeoff: May limit TCP routing capabilities.

#### Kubernetes — CVE-2026-100839 (CVSS 8.4 HIGH)
**Summary:** Contrast v1.0.0–v1.17.0 is vulnerable to AML injection in ACPI tables, enabling guest kernel RCE via malicious host-controlled tables.
**Affected Features / Interoperability:** OVMF firmware, ACPI/AML interpreter, confidential computing guest kernel. Could compromise guest memory and data integrity.
**Source:** [GitHub Advisory](https://github.com/edgelesssys/contrast/security/advisories/GHSA-g9ww-x58f-9g6m), [VulnCheck](https://www.vulncheck.com/advisories/contrast-before-1.18.0-aml-injection-remote-code-execution)
**Actions:**

- Workaround: Disable ACPI table passthrough; isolate host-guest communication.
- Tradeoff: May reduce firmware compatibility.
