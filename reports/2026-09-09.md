# Security Digest — 2026-09-09

## Database

The single most urgent item is **CVE-2026-9586** (Sangoma Switchvox → PostgreSQL SQL injection), confirmed actively exploited per CISA KEV with a due date of **2026-09-05**; all other findings, including critical CVSS scores, remain theoretical or unconfirmed exploitation and must be patched in parallel.

### Formal Vulnerabilities

#### MySQL — CVE-2026-72862 (CVSS 9.9 CRITICAL)
**Summary:** Dokploy database deployment functions pass user-controlled `dockerImage` values unquoted into `docker pull` shell commands on the remote-server path, allowing command injection.
**Affected Features / Interoperability:** Remote-server deployment of MariaDB, MongoDB, MySQL, Postgres, Redis, LibSQL via Dokploy.
**Source:** [GHSA-6jrh-8qmg-jj3p](https://github.com/Dokploy/dokploy/security/advisories/GHSA-6jrh-8qmg-jj3p), [v0.29.13 release](https://github.com/Dokploy/dokploy/releases/tag/v0.29.13)
**Actions:**
- Fix: v0.29.13
- Workaround: Quote or sanitize `dockerImage` inputs before shell execution.
- Tradeoff: May require deployment pipeline changes; no functional degradation if quoting is correct.

#### MySQL — CVE-2026-72869 (CVSS 9.9 CRITICAL)
**Summary:** Dokploy `backup.restoreBackupWithLogs` passes `databaseName` into nested shell text executed by Node.js `exec`; an authenticated user with `backup:restore` permission can achieve arbitrary command execution in the Docker-privileged host context.
**Affected Features / Interoperability:** Backup/restore for PostgreSQL, MariaDB, MySQL, MongoDB.
**Source:** [GHSA-f7mp-9jfp-mjrr](https://github.com/Dokploy/dokploy/security/advisories/GHSA-f7mp-9jfp-mjrr), [PR #4862](https://github.com/Dokploy/dokploy/pull/4862)
**Actions:**
- Fix: v0.29.13
- Workaround: Restrict `backup:restore` permission to trusted accounts.
- Tradeoff: Operational friction for backup restoration workflows.

#### MySQL — CVE-2026-73300 (CVSS 9.6 CRITICAL)
**Summary:** Budibase MySQL integration runs with `multipleStatements: true`, allowing attackers to inject malicious SQL through user input fields and compromise the database.

## Cloud Security

No CISA KEV-confirmed entries appear in this scope's data, so CVSS severity drives prioritization; the next tier consists of multiple CVSS 9.9 critical Docker/Dokploy vulnerabilities and CVSS 9.6 Kubernetes RBAC flaws.
