# Security Digest — 2026-08-28

## Database

The most urgent issue is CVE-2019-1068 in Microsoft SQL Server, a CISA KEV-confirmed remote code execution vulnerability actively exploited in the wild with a due date of August 29, 2026, requiring immediate mitigation or patching to prevent potential compromise of healthcare database systems.

### Formal Vulnerabilities

#### Microsoft SQL Server — CVE-2019-1068 (UNSCORED — CISA-confirmed active exploitation) 🔴 ACTIVELY EXPLOITED (CISA KEV)
**Summary:** A remote code execution vulnerability in Microsoft SQL Server allows attackers to execute code in the context of the SQL Server service account. This issue is actively exploited in the wild and was added to CISA's Known Exploited Vulnerabilities (KEV) catalog on August 26, 2026, with a mandatory remediation deadline of August 29, 2026.

**Affected Features / Interoperability:** The vulnerability impacts the SQL Server Database Engine service. Exploitation could lead to unauthorized access to sensitive healthcare data, disruption of database operations, and potential lateral movement within the enterprise environment.

**Source:** [https://nvd.nist.gov/vuln/detail/CVE-2019-1068](https://nvd.nist.gov/vuln/detail/CVE-2019-1068)

**Actions:**
- Fix: Apply the official Microsoft security update or patch as outlined in CISA's BOD 26-04 guidance.
- Workaround: If patching is not immediately possible, isolate affected SQL Server instances from external networks and enforce strict access controls.
- Tradeoff: Network isolation may disrupt legitimate remote database access for healthcare applications or administrative tools.

#### MongoDB — CVE-2026-19001 (CVSS 9.8 CRITICAL)
**Summary:** A buffer overflow vulnerability in the MongoDB BI Connector ODBC Driver can lead to memory corruption and arbitrary code execution when an application supplies an unusually long catalog, schema, or object name. This requires an attacker to control or impersonate the database server.

**Affected Features / Interoperability:** The BI Connector ODBC Driver is used for SQL-based analytics on MongoDB data. Exploitation could compromise applications using the driver, including business intelligence tools and reporting systems integrated with MongoDB.

**Source:** [https://github.com/mongodb/mongo-bi-connector-odbc-driver/releases/tag/v1.4.9](https://github.com/mongodb/mongo-bi-connector-odbc-driver/releases/tag/v1.4.9)

**Actions:**
- Fix: Upgrade to MongoDB BI Connector ODBC Driver version 1.4.9 or later.
- Workaround: Restrict access to the BI Connector and validate all metadata inputs from untrusted sources.
- Tradeoff: No significant tradeoff if the driver is not actively used; otherwise, disabling the BI Connector may limit analytics capabilities.

#### MySQL — CVE-2026-59335 (CVSS 8.7 HIGH)
**Summary:** A case-sensitivity bypass in Cloud Foundry UAA's identity zone authorization check allows authenticated attackers with limited privileges to escalate to system-level access when using MySQL as the backend. This affects UAA deployments with MySQL's default collation.

**Affected Features / Interoperability:** Impacts UAA deployments using MySQL. PostgreSQL and HSQLDB backends are unaffected. Exploitation could lead to forged JWTs and full compromise of Cloud Foundry environments relying on UAA for authentication.

**Source:** [https://www.cloudfoundry.org/blog/cve-2026-59335-uaa-case-insensitive-check-bypass/](https://www.cloudfoundry.org/blog/cve-2026-59335-uaa-case-insensitive-check-bypass/)

**Actions:**
- Fix: Upgrade UAA to a patched version that enforces case-sensitive comparisons.
- Workaround: Use PostgreSQL or HSQLDB backends instead of MySQL for UAA deployments.
- Tradeoff: Migrating backends may require configuration changes and testing in healthcare environments.

#### MongoDB — CVE-2026-18691 (CVSS 8.8 HIGH)
**Summary:** A vulnerability in MongoDB Server's intra-cluster connection setup allows attackers with network access to manipulate authentication mechanisms, potentially exposing internal credentials. This could enable unauthorized access to the internal superuser account.

**Affected Features / Interoperability:** Affects MongoDB replica sets. Exploitation could compromise cluster integrity and allow attackers to access all databases within the deployment.

**Source:** [https://jira.mongodb.org/browse/SERVER-130264](https://jira.mongodb.org/browse/SERVER-130264)

**Actions:**
- Fix: Apply the latest MongoDB Server update addressing this issue.
- Workaround: Restrict network access to MongoDB cluster nodes and monitor for unusual authentication patterns.
- Tradeoff: Network restrictions may impact replication or failover processes in distributed healthcare systems.

#### MongoDB — CVE-2026-18692 (CVSS 8.8 HIGH)
**Summary:** A use-after-free vulnerability in MongoDB Server's timeseries bucket lifecycle allows authenticated users with write privileges to trigger server crashes or arbitrary code execution.

**Affected Features / Interoperability:** Impacts MongoDB's timeseries collections. Exploitation could disrupt time-sensitive healthcare data logging or IoT device data ingestion pipelines.

**Source:** [https://jira.mongodb.org/browse/SERVER-129887](https://jira.mongodb.org/browse/SERVER-129887)

**Actions:**
- Fix: Upgrade to the patched MongoDB Server version.
- Workaround: Disable timeseries collections if not required or restrict write access to trusted users.
- Tradeoff: Disabling timeseries may limit time-series analytics for healthcare monitoring systems.

#### MongoDB — CVE-2026-18690 (CVSS 8.1 HIGH)
**Summary:** A privilege escalation flaw allows users with limited database-scoped roles to modify protected system collections, potentially dropping critical system data.

**Affected Features / Interoperability:** Affects MongoDB's system collections (e.g., `system.users`, `system.roles`). Exploitation could disrupt authentication, authorization, or database availability.

**Source:** [https://jira.mongodb.org/browse/SERVER-130481](https://jira.mongodb.org/browse/SERVER-130481)

**Actions:**
- Fix: Apply the latest MongoDB Server update.
- Workaround: Audit and restrict roles with write privileges to system collections.
- Tradeoff: Role restrictions may complicate administrative workflows in healthcare environments.

#### MongoDB — CVE-2026-18712 (CVSS 8.1 HIGH)
**Summary:** A metadata validation flaw in MongoDB's Queryable Encryption allows users with access to one encrypted collection to modify or delete data in other collections.

**Affected Features / Interoperability:** Impacts MongoDB's Queryable Encryption feature. Exploitation could compromise data confidentiality and integrity in encrypted healthcare records.

**Source:** [https://jira.mongodb.org/browse/SERVER-130633](https://jira.mongodb.org/browse/SERVER-130633)

**Actions:**
- Fix: Upgrade to the patched MongoDB Server version.
- Workaround: Disable Queryable Encryption if not required or enforce strict access controls.
- Tradeoff: Disabling encryption may violate healthcare data protection requirements (e.g., HIPAA).

#### PostgreSQL — CVE-2026-59335 (CVSS 8.7 HIGH)
**Summary:** This vulnerability is specific to MySQL backends in Cloud Foundry UAA and does not affect PostgreSQL deployments. The description is included for completeness but is not applicable to PostgreSQL systems.

**Affected Features / Interoperability:** Not applicable to PostgreSQL.

**Source:** [https://www.cloudfoundry.org/blog/cve-2026-59335-uaa-case-insensitive-check-bypass/](https://www.cloudfoundry.org/blog/cve-2026-59335-uaa-case-insensitive-check-bypass/)

**Actions:**
- Fix: No action required for PostgreSQL.
- Workaround: N/A.
- Tradeoff: N/A.

#### PostgreSQL — CVE-2026-10716 (No CVSS score)
**Summary:** An authenticated SQL injection vulnerability in Directus when using PostgreSQL with PostGIS allows administrators to create malicious geometry fields that execute arbitrary SQL.

**Affected Features / Interoperability:** Affects Directus applications using PostgreSQL with PostGIS. Exploitation could compromise database integrity and access to healthcare data managed through Directus.

**Source:** [https://github.com/directus/directus/releases#release-v12.1.0](https://github.com/directus/directus/releases#release-v12.1.0)

**Actions:**
- Fix: Upgrade Directus to version 12.1.0 or later.
- Workaround: Disable PostGIS or restrict administrator access to collection creation.
- Tradeoff: Disabling PostGIS may limit geospatial analytics in healthcare applications.

#### MySQL — CVE-2026-55215 (CVSS 7.5 HIGH)
**Summary:** A flaw in MariaDB Connector/Node.js allows credentials to be sent before certificate validation completes, enabling man-in-the-middle attacks to capture passwords.

**Affected Features / Interoperability:** Affects Node.js applications using MariaDB Connector to connect to MySQL/MariaDB. Exploitation could compromise database credentials and access to healthcare data.

**Source:** [https://github.com/mariadb-corporation/mariadb-connector-nodejs/releases/tag/3.3.3](https://github.com/mariadb-corporation/mariadb-connector-nodejs/releases/tag/3.3.3)

**Actions:**
- Fix: Upgrade to MariaDB Connector/Node.js versions 3.3.3, 3.4.6, or 3.5.3.
- Workaround: Enforce certificate pinning or use alternative connectors.
- Tradeoff: Certificate pinning may complicate deployment in dynamic healthcare environments.

#### MySQL — CVE-2026-55509 (No CVSS score)
**Summary:** A SQL injection vulnerability in WsgiDAV's MySQLBrowserProvider allows attackers to inject SQL via WebDAV requests if the provider is explicitly configured.

**Affected Features / Interoperability:** Affects WsgiDAV deployments using the non-default MySQLBrowserProvider. Exploitation could compromise data accessed through WebDAV shares.

**Source:** [https://github.com/mar10/wsgidav/releases/tag/v4.3.5](https://github.com/mar10/wsgidav/releases/tag/v4.3.5)

**Actions:**
- Fix: Upgrade WsgiDAV to version 4.3.5 or later.
- Workaround: Disable the MySQLBrowserProvider if not required.
- Tradeoff: Disabling the provider may limit WebDAV functionality for healthcare file sharing.
