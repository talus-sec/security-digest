# Security Digest — 2026-08-18

User Safety: safe

## Cloud Security

The most urgent issue is **CVE-2026-42880 in Kubernetes (Argo CD)**, a critical vulnerability (CVSS 9.6) allowing attackers with read-only access to extract plaintext Kubernetes Secrets via the Server-Side Apply dry-run mechanism. This flaw enables unauthorized data exfiltration and could compromise cluster secrets, including those used in healthcare systems for database and infrastructure access. Immediate patching to versions 3.2.11 or 3.3.9 is required, as no workaround fully mitigates the risk without disabling the affected functionality.

### Formal Vulnerabilities

#### Microsoft Azure — CVE-2026-66802 (CVSS 8.1 HIGH)  
**Summary:** A race condition in Azure Attestation and Device Health Attestation Services permits unauthorized network-based code execution. The vulnerability arises from improper synchronization of shared resources during concurrent operations.  
**Affected Features / Interoperability:** Azure Attestation service and Device Health Attestation Service components. Could disrupt device compliance checks and attestation workflows.  
**Source:** [Microsoft Security Response Center](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-66802)  
**Actions:**  
- Fix: Apply Azure service updates (version unspecified in data).  
- Workaround: Monitor for unusual concurrent attestation requests; no direct mitigation available.  
- Tradeoff: No significant tradeoff.  

#### Microsoft Azure — CVE-2026-71331 (CVSS 8.1 HIGH)  
**Summary:** An integer overflow in Azure Attestation and Device Health Attestation Services allows network-based code execution by an unauthorized attacker.  
**Affected Features / Interoperability:** Same as CVE-2026-66802.  
**Source:** [Microsoft Security Response Center](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-71331)  
**Actions:**  
- Fix: Apply Azure service updates (version unspecified in data).  
- Workaround: Same as CVE-2026-66802.  
- Tradeoff: No significant tradeoff.  

#### Google Cloud Platform — CVE-2026-15623 (UNSCORED)  
**Summary:** A SQL injection vulnerability in Google Cloud Google SecOps (Chronicle SOAR) versions prior to 6.3.85 allows authenticated attackers to execute blind SQL queries via crafted request parameters.  
**Affected Features / Interoperability:** Legacy dashboard widget API in Chronicle SOAR. Could compromise SOAR automation workflows and data integrity.  
**Source:** [Google Cloud Release Notes](https://docs.cloud.google.com/chronicle/docs/soar/release-notes#May_23_2026)  
**Actions:**  
- Fix: Upgrade to version 6.3.85 or later (no customer action required per advisory).  
- Workaround: N/A (patch is automatic).  
- Tradeoff: No significant tradeoff.  

#### Kubernetes — CVE-2026-42880 (CVSS 9.6 CRITICAL)  
**Summary:** Argo CD versions 3.2.0–3.2.10 and 3.3.0–3.3.8 have a missing authorization gap in the ServerSideDiff endpoint, enabling read-only users to extract Kubernetes Secrets via Server-Side Apply dry-run.  
**Affected Features / Interoperability:** Argo CD’s Server-Side Diff functionality. Could expose secrets used in GitOps workflows, including database credentials and Vault tokens.  
**Source:** [Argo CD Security Advisory](https://github.com/argoproj/argo-cd/security/advisories/GHSA-3v3m-wc6v-x4x3), [Red Hat Errata](https://access.redhat.com/errata/RHBA-2026:12433)  
**Actions:**  
- Fix: Upgrade to Argo CD 3.2.11 or 3.3.9.  
- Workaround: Disable Server-Side Diff feature or restrict API access to admin-only users.  
- Tradeoff: Disables Server-Side Diff functionality, impacting GitOps diff comparisons.  

#### Kubernetes — CVE-2026-73842 (CVSS 9.0 CRITICAL)  
**Summary:** OpenChoreo versions prior to 1.0.3/1.1.3/1.2.0-rc.2 expose internal APIs without mTLS or token authentication, allowing network attackers to read secrets, mutate workloads, and execute commands.  
**Affected Features / Interoperability:** OpenChoreo’s internal cluster-gateway proxy endpoints. Could compromise all connected Kubernetes clusters and tenant workloads.  
**Source:** [OpenChoreo Commit Fixes](https://github.com/openchoreo/openchoreo/commit/50fcae3f1753fd0ac3ae655a3fc080a761c49c04)  
**Actions:**  
- Fix: Upgrade to 1.0.3, 1.1.3, or 1.2.0-rc.2.  
- Workaround: Restrict network access to internal cluster-gateway listener.  
- Tradeoff: Limits OpenChoreo’s internal API accessibility.  

#### Kubernetes — CVE-2026-73667 (CVSS 8.8 HIGH)  
**Summary:** OpenChoreo Workflow Plane templates prior to 1.0.4/1.1.4/1.2.0-rc.2 allow arbitrary command execution via shell interpolation of user-controlled parameters in workflow pods.  
**Affected Features / Interoperability:** OpenChoreo workflow templates. Could enable privilege escalation in workflow execution environments.  
**Source:** [OpenChoreo Commit Fixes](https://github.com/openchoreo/openchoreo/commit/017c3c6d8b27c21d11c8c2b43da1846aa7ae73b9)  
**Actions:**  
- Fix: Upgrade to 1.0.4, 1.1.4, or 1.2.0-rc.2.  
- Workaround: Audit and restrict workflow template parameters.  
- Tradeoff: May require reworking existing workflow templates.  

#### Kubernetes — CVE-2026-17107 (CVSS 8.5 HIGH)  
**Summary:** A flaw in Red Hat ACM’s cluster-proxy allows hub principals to escalate to cluster-admin on managed clusters via Impersonate-Group header injection.  
**Affected Features / Interoperability:** Red Hat Advanced Cluster Management multicluster proxy. Could compromise all managed clusters under ACM control.  
**Source:** [Red Hat Errata](https://access.redhat.com/errata/RHSA-2026:46885)  
**Actions:**  
- Fix: Apply RHACM/RHACM-MCE updates per errata.  
- Workaround: Restrict hub principal impersonation permissions.  
- Tradeoff: Limits hub cluster administrative flexibility.  

#### Kubernetes — CVE-2026-4740 (CVSS 8.2 HIGH)  
**Summary:** Open Cluster Management certificate renewal validation flaws allow managed cluster admins to forge client certificates, enabling cross-cluster privilege escalation.  
**Affected Features / Interoperability:** OCM/RHACM certificate management. Could grant attackers control over hub and managed clusters.  
**Source:** [Red Hat Errata](https://access.redhat.com/errata/RHSA-2026:11414)  
**Actions:**  
- Fix: Apply OCM/RHACM updates per errata.  
- Workaround: Manually validate certificate renewal requests.  
- Tradeoff: Increases administrative overhead for certificate management.  

#### Kubernetes — CVE-2026-9165 (CVSS 7.7 HIGH)  
**Summary:** RHACS Central’s GraphQL API lacks query depth limits, enabling authenticated users to cause denial of service via deeply nested queries.  
**Affected Features / Interoperability:** RHACS Central management plane. Could disrupt security monitoring and compliance reporting.  
**Source:** [Red Hat Errata](https://access.redhat.com/errata/RHSA-2026:36207)  
**Actions:**  
- Fix: Apply RHACS updates per errata.  
- Workaround: Restrict API token usage and monitor query patterns.  
- Tradeoff: May limit advanced GraphQL query capabilities.  

#### Docker — CVE-2026-41567 (CVSS 7.2 HIGH)  
**Summary:** Moby/Docker Engine versions prior to 29.5.1 (or v2.0.0-beta.14) resolve decompression binaries from untrusted container filesystems, enabling arbitrary code execution with daemon privileges.  
**Affected Features / Interoperability:** Docker’s `PUT /containers/{id}/archive` and `docker cp` commands. Could compromise host root access via malicious container images.  
**Source:** [Moby Security Advisory](https://github.com/moby/moby/security/advisories/GHSA-x86f-5xw2-fm2r)  
**Actions:**  
- Fix: Upgrade to Docker Engine 29.5.1 or moby/moby v2.0.0-beta.14.  
- Workaround: Restrict `docker cp` usage and only use trusted images.  
- Tradeoff: Limits container image flexibility.  

#### Docker — CVE-2026-33997 (CVSS 6.8 MEDIUM)  
**Summary:** Docker plugin install privilege validation bypass in versions prior to 29.3.1 allows unauthorized plugin privilege escalation.  
**Affected Features / Interoperability:** Docker plugin management. Could enable unauthorized access to host resources via malicious plugins.  
**Source:** [Docker Release Notes](https://github.com/moby/moby/releases/tag/docker-v29.3.1)  
**Actions:**  
- Fix: Upgrade to Docker 29.3.1.  
- Workaround: Audit installed plugins and restrict plugin installation permissions.  
- Tradeoff: No significant tradeoff.
