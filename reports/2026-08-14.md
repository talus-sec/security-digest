# Security Digest — 2026-08-14

## Database

The most urgent issue is CVE-2026-72862 in MySQL/Redis (Dokploy), a CRITICAL vulnerability (CVSS 9.9) confirmed by CISA KEV, allowing unauthenticated remote code execution via Docker image pull command injection. PostgreSQL faces multiple HIGH-severity heap buffer overflows and type confusion flaws (CVE-2026-14662, CVE-2026-14664, etc.) enabling arbitrary code execution. MongoDB's BI Connector ODBC Driver has CRITICAL buffer overflow vulnerabilities (CVE-2026-19001) and Oracle Database/Budibase integrations expose SQL injection risks (CVE-2026-72853). Microsoft SQL Server users should address an unauthenticated SQL injection in Hongjing e-HR (CVE-2024-58374). All PostgreSQL and MongoDB vulnerabilities require immediate patching to prevent exploitation.

### Formal Vulnerabilities

#### MySQL — CVE-2026-72862 (CVSS 9.9 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)
**Summary:** Dokploy versions prior to 0.29.13 pass user-controlled Docker image names unquoted into shell commands during remote server deployments, enabling arbitrary command execution. Attackers can inject malicious Docker images via the `dockerImage` field to execute commands on the target server.

**Affected Features / Interoperability:** Docker image deployment functionality in Dokploy's remote server code path. Breaks container orchestration workflows if `dockerImage` input is sanitized.

**Source:** https://github.com/Dokploy/dokploy/security/advisories/GHSA-6jrh-8qmg-jj3p

**Actions:**
- Fix: Upgrade to Dokploy v0.29.13 or later.
- Workaround: Restrict `dockerImage` input to trusted administrators; avoid exposing deployment endpoints to untrusted users.
- Tradeoff: No significant tradeoff if input validation is enforced.

#### PostgreSQL — CVE-2026-14662 (CVSS 8.8 HIGH)
**Summary:** Integer wraparound in tsvector/tsquery functions allows unprivileged users to trigger out-of-bounds writes, potentially executing arbitrary code as the database OS user. Exploitation requires crafting large inputs to these text search types.

**Affected Features / Interoperability:** Text search functionality (tsvector, tsquery). Impacts applications using full-text search; replication and extensions relying on these types may fail.

**Source:** https://www.postgresql.org/support/security/CVE-2026-14662/

**Actions:**
- Fix: Upgrade to PostgreSQL 18.5, 17.11, 16.15, 15.19, or 14.24.
- Workaround: Audit and restrict user permissions on text search functions.
- Tradeoff: No significant tradeoff.

#### PostgreSQL — CVE-2026-14664 (CVSS 8.8 HIGH)
**Summary:** Heap buffer overflow in regexp functions allows query authors to execute arbitrary code via crafted regex patterns that bypass encoding validation.

**Affected Features / Interoperability:** Regular expression processing. Breaks applications using complex regex queries; extensions relying on regex may malfunction.

**Source:** https://www.postgresql.org/support/security/CVE-2026-14664/

**Actions:**
- Fix: Upgrade to patched versions listed above.
- Workaround: Validate regex inputs; disable untrusted user-created regex functions.
- Tradeoff: May limit regex functionality in applications.

#### PostgreSQL — CVE-2026-14669 (CVSS 8.8 HIGH)
**Summary:** Heap buffer overflow in `to_char(timestamptz)` allows timezone attackers to execute code via long POSIX timezone abbreviations.

**Affected Features / Interoperability:** Timestamp formatting with timezone. Affects applications using dynamic timezone settings; replication may fail if timezone data is corrupted.

**Source:** https://www.postgresql.org/support/security/CVE-2026-14669/

**Actions:**
- Fix: Upgrade to patched versions.
- Workaround: Restrict timezone input to predefined values.
- Tradeoff: Limits dynamic timezone configuration.

#### PostgreSQL — CVE-2026-14670 (CVSS 8.8 HIGH)
**Summary:** Heap buffer overflow in plperl function returns allows function owners to execute code via crafted function bodies.

**Affected Features / Interoperability:** Perl procedural language extensions. Breaks existing plperl functions; impacts applications using Perl-based stored procedures.

**Source:** https://www.postgresql.org/support/security/CVE-2026-14670/

**Actions:**
- Fix: Upgrade to patched versions.
- Workaround: Disable plperl for untrusted users.
- Tradeoff: Disables Perl-based extensions.

#### PostgreSQL — CVE-2026-15741 (CVSS 8.8 HIGH)
**Summary:** SQL injection in EXTRACT() deparse allows object owners to execute arbitrary SQL as superuser via hostile object definitions.

**Affected Features / Interoperability:** Schema dump tools (pg_dump, psql \sf). Breaks backup/restore workflows; impacts third-party tools using expression deparse.

**Source:** https://www.postgresql.org/support/security/CVE-2026-15741/

**Actions:**
- Fix: Upgrade to patched versions.
- Workaround: Audit object definitions; restrict object ownership.
- Tradeoff: May require manual schema validation.

#### MongoDB — CVE-2026-19001 (CVSS 9.8 CRITICAL)
**Summary:** Buffer overflow in BI Connector ODBC Driver when processing long catalog/schema names, leading to memory corruption and potential code execution.

**Affected Features / Interoperability:** BI Connector ODBC Driver. Breaks BI tools connecting via ODBC; impacts Power BI, Tableau integrations.

**Source:** https://github.com/mongodb/mongo-bi-connector-odbc-driver/releases/tag/v1.4.9

**Actions:**
- Fix: Upgrade to v1.4.9.
- Workaround: Validate object names before BI Connector queries.
- Tradeoff: May require application-level input validation.

#### Oracle Database — CVE-2026-72853 (CVSS 7.6 HIGH)
**Summary:** SQL injection in Budibase Oracle connector's post-write row lookup via unescaped table names with double quotes.

**Affected Features / Interoperability:** Oracle datasource integration in Budibase. Breaks Oracle data access; impacts applications using Budibase with Oracle.

**Source:** https://github.com/Budibase/budibase/security/advisories/GHSA-xj29-x47g-9w2c

**Actions:**
- Fix: Upgrade Budibase to v3.40.0.
- Workaround: Avoid table names with double quotes; audit existing tables.
- Tradeoff: Limits Oracle table naming conventions.

#### Microsoft SQL Server — CVE-2024-58374 (CVSS 7.5 HIGH)
**Summary:** Unauthenticated SQL injection in Hongjing e-HR's getSdutyTree endpoint via path traversal in `codeitemid` parameter.

**Affected Features / Interoperability:** Hongjing e-HR application. Breaks HR system functionality; impacts credential security.

**Source:** https://www.vulncheck.com/advisories/hongjing-e-hr-unauthenticated-sql-injection-via-getsdutytree

**Actions:**
- Fix: Patch Hongjing e-HR application.
- Workaround: Block path traversal sequences in `codeitemid` parameter.
- Tradeoff: May break legitimate HR queries using special characters.

#### Redis — CVE-2026-72862 (CVSS 9.9 CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)

**Affected Features / Interoperability:** Redis deployment functionality in Dokploy. Breaks container deployments; impacts Redis-as-a-Service workflows.

**Source:** https://github.com/Dokploy/dokploy/security/advisories/GHSA-6jrh-8qmg-jj3p

**Actions:**

- Tradeoff: No significant tradeoff.
