Scoped Vulnerability Tracking

Database

No CISA KEV-confirmed database vulnerabilities were reported today; the single most urgent item is PostgreSQL CVE-2026-82039 (CVSS 8.8 HIGH), an authenticated SQL injection in UTMStack that allows attackers to execute arbitrary SQL with DBA privileges via the searchGroupsByFilter endpoint, enabling full database read/write and potential filesystem access.

Formal Vulnerabilities

MySQLCVE-2026-103231CVSS 7.3 · HIGH

Summary: SQL injection in the Restaurant-Management-System's User/cancel.php via unsanitized ID parameter passed to mysqli_query; remotely exploitable without authentication.

Affected Features / Interoperability: Web application order cancellation component; direct database manipulation/read via the injection point.

Source: https://github.com/AdithyaYelloju/Restaurant-Management-System/, https://vuldb.com/cve/CVE-2026-103231, https://vuldb.com/submit/955080, https://vuldb.com/vuln/411924

Actions:

  • Fix: No patch available; project unresponsive to early issue report.
  • Workaround: Sanitize/validate the ID parameter; restrict network access to the application.
  • Tradeoff: Input filtering may break legitimate order cancellations if rules are too strict.
PostgreSQLCVE-2026-82039CVSS 8.8 · HIGH

Summary: Authenticated SQL injection in UTMStack UtmAssetGroupService.searchQueryBuilder() via assetType/groupName values inserted unsanitized into a native PostgreSQL query; exploitable through GET /api/utm-asset-groups/searchGroupsByFilter.

Affected Features / Interoperability: UTMStack asset group search API; could allow full database read/modification and filesystem access via DBA privileges.

Source: https://github.com/UTMStack/UTMStack/releases/tag/v11.2.16, https://github.com/utmstack/UTMStack/commit/4e7a727c3b8d8e2ad020d3b4f982a6d085dbecdd, https://www.vulncheck.com/advisories/utmstack-sql-injection-via-searchgroupsbyfilter

Actions:

  • Fix: Upgrade to UTMStack 11.2.16 or later.
  • Workaround: Restrict access to the searchGroupsByFilter endpoint; enforce strong authentication.
  • Tradeoff: Endpoint restriction may hinder legitimate asset group searches for authorized users.
PostgreSQLCVE-2026-104055UNSCORED

Summary: postgresql-operator charm's postgres_exporter writes the monitoring user's password in cleartext to logs on database connection errors.

Affected Features / Interoperability: Prometheus monitoring integration; any log reader can recover pg_monitor read-only credentials.

Source: https://github.com/canonical/postgresql-operator/security/advisories/GHSA-rcx7-7rh5-r542

Actions:

  • Fix: Upgrade to dev track revisions 1189/1190 (arm64/amd64) or stable track 1216/1217 (arm64/amd64).
  • Workaround: Restrict log access to trusted principals; rotate monitoring password after deployment.
  • Tradeoff: Log access restrictions may slow troubleshooting; password rotation requires exporter restart.
Oracle DatabaseCVE-2026-104460CVSS 7.5 · HIGH

Summary: Blind SQL injection in YesWiki {{newtextsearch}} action via unsanitized Bazar list option ids concatenated into SQL REGEXP/LIKE clauses; exploitable anonymously.

Affected Features / Interoperability: YesWiki Bazar list search; can leak admin password hashes from yeswiki_users table.

Source: https://github.com/YesWiki/yeswiki/security/advisories/GHSA-4333-x9p4-8xj7, https://www.vulncheck.com/advisories/yeswiki-before-4.6.7-unauthenticated-blind-sql-injection-via-newtextsearch

Actions:

  • Fix: Upgrade to YesWiki 4.6.7 or later.
  • Workaround: Disable anonymous editing of Bazar lists or block the {{newtextsearch}} action.
  • Tradeoff: Disabling anonymous editing reduces collaboration functionality.
