Scoped Vulnerability Tracking

Database

The most urgent vulnerability is CVE-2026-61781 in PostgreSQL's pg_partman extension (CVSS 9.9 CRITICAL), which allows authenticated attackers with partman_user privileges to escalate to superuser and execute arbitrary OS commands via SQL injection in partition maintenance functions. This flaw enables full database and system compromise, requiring immediate patching to version 5.5.0.

Formal Vulnerabilities

PostgreSQLCVE-2026-61781CVSS 9.9 · CRITICAL

Summary: A SQL injection vulnerability in pg_partman's create_partition_time() function allows authenticated users with partman_user privileges to inject malicious SQL that executes with superuser privileges when the background worker creates partitions. This can lead to full database compromise and OS command execution as the PostgreSQL service account.

Affected Features / Interoperability: The pg_partman extension's partition creation and maintenance functions, specifically the time_encoder configuration parameter and background worker (pg_partman_bgw) role. Exploitation affects all systems using pg_partman for time-based partitioned tables.

Source: https://github.com/pgpartman/pg_partman/commit/ba9405542acf24dd881845b935cab8b165854361, https://github.com/pgpartman/pg_partman/releases/tag/v5.5.0, https://github.com/pgpartman/pg_partman/security/advisories/GHSA-742w-3j7c-qwvp

Actions:

  • Fix: Upgrade to pg_partman version 5.5.0
  • Workaround: Disable pg_partman_bgw.role or restrict partman_user privileges (may break partition maintenance automation)
  • Tradeoff: Disabling background worker halts automated partition management
