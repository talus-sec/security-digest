Scoped Vulnerability Tracking

Database

The most urgent vulnerability is CVE-2026-58491 in Warpgate, a Critical-level SSRF flaw that enables remote code execution and data exfiltration through SSO endpoints, making it a top priority despite being slightly less publicized than some high-CVSS issues. This flaw allows attackers to hijack authenticated sessions and execute arbitrary commands on the bastion host, posing an immediate risk to database environments that integrate with Warpgate.

Formal Vulnerabilities

MySQL

[MySQL] — CVE-2026-58491 (CVSS 9.3) (CRITICAL) 🔴 ACTIVELY EXPLOITED (CISA KEV)

Summary: Warpgate’s SSO endpoint contains an SSRF vulnerability where an attacker can manipulate the `/@warpgate/api/sso/return` path to trigger arbitrary code execution or data exfiltration via open redirects and unescaped parameters.

Affected Features / Interoperability: The Warpgate bastion host SSO flow (`/@warpgate/api/sso/*`) and HTTP API endpoints are directly impacted, allowing attackers to reach internal services and execute commands remotely.

Source: https://github.com/warp-tech/warpgate/commit/eab0548f018d95b5f96f8e913527000e05ed93a2, https://github.com/warp-tech/warpgate/releases/tag/v0.25.5, https://github.com/warp-tech/warpgate/security/advisories/GHSA-3c3w-75j2-7h74

Actions:

  • Fix: Upgrade to version 0.25.5 or later.
  • Workaround: Disable SSO functionality or restrict SSO access to trusted domains only.
  • Tradeoff: Removing SSO
