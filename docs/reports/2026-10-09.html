Scoped Vulnerability Tracking

User Safety: safe

Cloud Security

The most urgent issue is CVE-2026-85594 in Traefik (Kubernetes), a CISA KEV-confirmed critical vulnerability allowing namespace bypass and credential theft via misconfigured middleware injection. Immediate patching to v3.7.12 is required. Additional critical vulnerabilities in Traefik, Crawl4AI, and Contrast require urgent attention, with two more KEV entries (CVE-2026-85596 and CVE-2026-88877) demanding immediate remediation. Docker and Kubernetes systems face active exploitation risks, while Contrast’s confidential computing runtime has multiple high-severity flaws affecting integrity and access controls.

Formal Vulnerabilities

KubernetesCVE-2026-85594CVSS 9.8 · CRITICALActively exploited · CISA KEV

Summary: Traefik v3.7.1 fails to enforce crossProviderNamespaces restrictions, allowing namespace-limited tenants to inject operator-owned middlewares and recover backend credentials. Exploitable via Kubernetes Ingress provider annotations.

Affected Features / Interoperability: Kubernetes Ingress provider, Service annotations, middleware injection. Could compromise backend credentials and tenant isolation.

Source: GitHub Advisory, VulnCheck

Actions:

  • Fix: Upgrade to Traefik v3.7.12.
  • Workaround: Restrict tenant access to Service annotations; audit middleware usage.
  • Tradeoff: No significant tradeoff if patched immediately.
KubernetesCVE-2026-85596CVSS 9.8 · CRITICALActively exploited · CISA KEV

Summary: Traefik v3.7.0–v3.7.10 has an authentication bypass in Kubernetes Ingress NGINX provider due to TLS option naming conflicts, allowing unauthenticated access to protected routes.

Affected Features / Interoperability: TLS configuration, NGINX Ingress provider, client certificate authentication. Could bypass TLS client verification.

Source: GitHub Advisory, VulnCheck

Actions:

  • Fix: Upgrade to Traefik v3.7.11.
  • Workaround: Disable conflicting Ingress routes; enforce strict TLS option naming.
  • Tradeoff: May require reconfiguration of TLS settings.
KubernetesCVE-2026-88877CVSS 9.8 · CRITICALActively exploited · CISA KEV

Summary: Traefik v3.7.0–v3.7.11 mishandles Ingresses with both authentication and www-redirect annotations, creating a sibling router that bypasses authentication for non-matching requests.

Affected Features / Interoperability: Ingress authentication, redirect middleware, host matching. Could expose protected backends without authentication.

Source: GitHub Advisory, VulnCheck

Actions:

  • Fix: Upgrade to Traefik v3.7.12.
  • Workaround: Avoid combining authentication and redirect annotations; validate host patterns.
  • Tradeoff: May require restructuring Ingress configurations.
KubernetesCVE-2026-100833CVSS 9.6 · CRITICAL

Summary: Contrast v1.14.0–v1.23.1 generates runtime policies that fail to verify container image digests, allowing image substitution via Kata agent API.

Affected Features / Interoperability: Container image policies, Kata Containers, confidential computing integrity. Could enable arbitrary code execution in confidential containers.

Source: GitHub Advisory, VulnCheck

Actions:

  • Fix: Upgrade to Contrast v1.23.1.
  • Workaround: Manually enforce image digest verification in policies.
  • Tradeoff: May require policy adjustments.

Affected Features / Interoperability: Karavan deployment, Kubernetes resource management, pod security options. Could allow hostNetwork, privileged containers, or capability escalation.

Source: Apache Advisory, GitHub Commit

Actions:

  • Fix: Upgrade to Karavan v4.22.1.
  • Workaround: Restrict Karavan’s service account permissions; validate `kubernetes.yaml` before deployment.
  • Tradeoff: May slow deployment workflows.
