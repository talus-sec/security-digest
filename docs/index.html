Scoped Vulnerability Tracking

User Safety: safe

Cloud Security

The most urgent issue is CVE-2026-42880 in Kubernetes (Argo CD), a critical vulnerability (CVSS 9.6) allowing attackers with read-only access to extract plaintext Kubernetes Secrets via the Server-Side Apply dry-run mechanism. This flaw enables unauthorized data exfiltration and could compromise cluster secrets, including those used in healthcare systems for database and infrastructure access. Immediate patching to versions 3.2.11 or 3.3.9 is required, as no workaround fully mitigates the risk without disabling the affected functionality.

Formal Vulnerabilities

Microsoft Azure — CVE-2026-66802 (CVSS 8.1 HIGH)

Summary: A race condition in Azure Attestation and Device Health Attestation Services permits unauthorized network-based code execution. The vulnerability arises from improper synchronization of shared resources during concurrent operations.

Affected Features / Interoperability: Azure Attestation service and Device Health Attestation Service components. Could disrupt device compliance checks and attestation workflows.

Source: Microsoft Security Response Center

Actions:

  • Fix: Apply Azure service updates (version unspecified in data).
  • Workaround: Monitor for unusual concurrent attestation requests; no direct mitigation available.
  • Tradeoff: No significant tradeoff.

Microsoft Azure — CVE-2026-71331 (CVSS 8.1 HIGH)

Summary: An integer overflow in Azure Attestation and Device Health Attestation Services allows network-based code execution by an unauthorized attacker.

Affected Features / Interoperability: Same as CVE-2026-66802.

Source: Microsoft Security Response Center

Actions:

  • Fix: Apply Azure service updates (version unspecified in data).
  • Workaround: Same as CVE-2026-66802.
  • Tradeoff: No significant tradeoff.

Google Cloud Platform — CVE-2026-15623 (UNSCORED)

Summary: A SQL injection vulnerability in Google Cloud Google SecOps (Chronicle SOAR) versions prior to 6.3.85 allows authenticated attackers to execute blind SQL queries via crafted request parameters.

Affected Features / Interoperability: Legacy dashboard widget API in Chronicle SOAR. Could compromise SOAR automation workflows and data integrity.

Source: Google Cloud Release Notes

Actions:

  • Fix: Upgrade to version 6.3.85 or later (no customer action required per advisory).
  • Workaround: N/A (patch is automatic).
  • Tradeoff: No significant tradeoff.

Kubernetes — CVE-2026-42880 (CVSS 9.6 CRITICAL)

Summary: Argo CD versions 3.2.0–3.2.10 and 3.3.0–3.3.8 have a missing authorization gap in the ServerSideDiff endpoint, enabling read-only users to extract Kubernetes Secrets via Server-Side Apply dry-run.

Affected Features / Interoperability: Argo CD’s Server-Side Diff functionality. Could expose secrets used in GitOps workflows, including database credentials and Vault tokens.

Source: Argo CD Security Advisory, Red Hat Errata

Actions:

  • Fix: Upgrade to Argo CD 3.2.11 or 3.3.9.
  • Workaround: Disable Server-Side Diff feature or restrict API access to admin-only users.
  • Tradeoff: Disables Server-Side Diff functionality, impacting GitOps diff comparisons.

Kubernetes — CVE-2026-73842 (CVSS 9.0 CRITICAL)

Summary: OpenChoreo versions prior to 1.0.3/1.1.3/1.2.0-rc.2 expose internal APIs without mTLS or token authentication, allowing network attackers to read secrets, mutate workloads, and execute commands.

Affected Features / Interoperability: OpenChoreo’s internal cluster-gateway proxy endpoints. Could compromise all connected Kubernetes clusters and tenant workloads.

Source: OpenChoreo Commit Fixes

Actions:

  • Fix: Upgrade to 1.0.3, 1.1.3, or 1.2.0-rc.2.
  • Workaround: Restrict network access to internal cluster-gateway listener.
  • Tradeoff: Limits OpenChoreo’s internal API accessibility.

Kubernetes — CVE-2026-73667 (CVSS 8.8 HIGH)
